Keyboard shortcuts

codec is keyboard-first: every action has a shortcut or a palette entry. Press ? anywhere (outside a text field) to see the main ones. On macOS, Ctrl is ⌘.

Everywhere#

KeysAction
Ctrl KCommand palette: every action, view and file command
Ctrl PGo to file
Ctrl OOpen folder
Ctrl ,Settings
Ctrl Shift EToggle the explorer
Ctrl Shift FFind in files
Ctrl BToggle the sidebar (icons only / labels)
?Show keyboard shortcuts

In the editor#

KeysAction
F12 or Ctrl+clickGo to definition
Ctrl SpaceSuggestions: schema keys and values, anchors after *, snippets
Tab / Shift TabNext / previous field of a snippet
Ctrl FFind (and replace, in what-if edits)
Ctrl GGo to line
Ctrl Z / Ctrl Shift ZUndo / redo

In a tool#

KeysAction
Ctrl EnterRun the transform
Alt CCopy the output
Alt SUse the output as input
EscClear input and output

Trees, lists and dialogs#

KeysAction
↑ ↓Move (explorer, outline, palette, Go to file)
→ / ←Expand / collapse a folder or outline node; ← on a leaf jumps to its parent
Home / EndFirst / last row
Enter or SpaceOpen or toggle
Ctrl+click or Ctrl SpaceSelect a file in the explorer (for "Compare selected"); Esc clears the selection
Shift F10 or the menu keyThe explorer's context menu for the focused file
EscClose the palette, a dialog or a menu

Segmented controls and radio groups move with the arrow keys. Focus is always visible when you use the keyboard.
