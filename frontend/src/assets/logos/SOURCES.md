# Logo sources

Brand logos label file types only (e.g. a Helm chart in the file tree).
They are bundled here as SVG and never fetched at runtime. Record every
file you add: where it came from and under what terms. Prefer official
sources: the CNCF artwork repo (github.com/cncf/artwork) for Kubernetes,
Helm and Argo; Simple Icons (simpleicons.org) or the vendor's brand page
for others.

All files below are unmodified single-colour marks from
[Simple Icons](https://simpleicons.org) v16.32.0 (npm `simple-icons`),
released under CC0 1.0. The marks remain trademarks of their owners and
are used only to identify file types. Colours are applied in
`tokens.css` (`--brand-*`), lightened where needed for the dark theme.

| File | Mark | Upstream source (per Simple Icons) |
|---|---|---|
| kubernetes.svg | Kubernetes | github.com/kubernetes/kubernetes/tree/master/logo |
| helm.svg | Helm | helm.sh |
| argo.svg | Argo | github.com/cncf/artwork (projects/argo) |
| githubactions.svg | GitHub Actions | github.com/features/actions |
| gitlab.svg | GitLab | about.gitlab.com/press/press-kit |
| ansible.svg | Ansible | ansible.com/logos |
| docker.svg | Docker | docker.com/company/newsroom/media-resources |
| terraform.svg | Terraform | hashicorp.com/brand |
| yaml.svg | YAML | commons.wikimedia.org/wiki/File:Official_YAML_Logo.svg |
| markdown.svg | Markdown | github.com/dcurtis/markdown-mark |

Not available from Simple Icons (Microsoft marks were removed): Azure
Pipelines uses a generic Lucide icon in the Azure colour instead.
