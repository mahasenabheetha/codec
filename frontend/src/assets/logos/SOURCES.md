# Logo sources

Brand logos label file types only (e.g. a Helm chart in the file tree).
They are bundled here as SVG and never fetched at runtime. Record every
file you add: where it came from and under what terms. Prefer official
sources: the CNCF artwork repo (github.com/cncf/artwork) for Kubernetes,
Helm and Argo; Simple Icons (simpleicons.org) or the vendor's brand page
for others.
