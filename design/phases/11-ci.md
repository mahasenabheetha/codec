# 11 — CI pipelines lens

**Goal:** see a pipeline's real shape: jobs, order, and the effective
config after includes/templates.
**Depends on:** 09 · **Branch:** `feature/mab/p11-ci`

## Scope

- GitHub Actions: jobs/steps outline, `needs` graph, matrix expansion
  preview, local composite actions and reusable workflows
  (`workflow_call`) resolved, `${{ }}` highlight + hover for known
  contexts (inputs, env, secrets names only).
- GitLab CI: stages/jobs, `needs`/stage-order graph, effective job view
  after `extends`, anchors and `!reference`; `include: local` resolved,
  remote/project includes shown as unresolved.
- Azure Pipelines: stages/jobs/steps, local `template:` resolution,
  `${{ }}` and `$( )` variable highlighting.
- Schema validation for all three via phase 07.

## Acceptance

- [ ] GitLab job with `extends` + anchors shows the correct effective config.
- [ ] GitHub matrix preview lists every combination incl. include/exclude.
- [ ] Graphs match the actual execution order.

**Go concepts:** custom YAML tags, deep merge semantics per tool.
